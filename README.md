# Цены на новые авто в Казахстане

Раз в день собирает цены с официальных сайтов дистрибьюторов и сохраняет их в `data/`.

| Файл | Что внутри |
|---|---|
| `data/latest.csv` | актуальные цены: бренд, модель, комплектация, тип цены, цена, срок акции, источник |
| `data/history.csv` | все изменения цен по датам |
| `data/changes.md` | что изменилось сегодня и самые большие скидки (удобно для постов) |
| `data/status.json` | какие сайты собрались, а какие нет |
| `data/pdf/` | последние версии PDF-прайсов |

## Источники

| Бренд | Сайт | Что собирается |
|---|---|---|
| Hyundai, Genesis | hyundai.kz | цена «от» по моделям (комплектации сайт в HTML не отдаёт) |
| Chery | chery.kz | цена «от», PDF-прайсы: прайсовая и акционная цена по комплектациям, срок акции |
| Haval / GWM | haval-motor.kz | PDF-прайсы: прайсовая цена и цена с максимальной выгодой по комплектациям |
| Toyota | toyotakz.com | PDF-прайсы: цены по комплектациям, цена «от» = минимальная из прайса |

Тип цены в колонке `kind`: `от` (стартовая цена модели), `прайс` (цена комплектации по прайсу),
`акция` (акционная цена или цена с учётом максимальной выгоды из того же прайса).

Kia, Geely и Chevrolet не собираются: их сайты запрещают автоматический доступ.
Парсер всегда проверяет robots.txt и не обходит защиту сайтов.

Если сайт не ответил или поменял вёрстку, в `latest.csv` остаются вчерашние цены,
а в `changes.md` и `status.json` это помечается.

## Отладка

Если сайт поменял вёрстку: Actions → «Отладка вёрстки» → Run workflow, указать адреса страниц.
В логе будут ссылки, найденные цены и ключи JSON со страницы.

## Запуск

Автоматически: GitHub Actions каждый день (файл `.github/workflows/daily.yml`).
Вручную: вкладка Actions → «Ежедневный сбор цен» → Run workflow.

Локально:

```
pip install -r requirements.txt
python -m unittest discover -s tests
python -m scraper.run
```

Данные носят справочный характер: окончательную цену устанавливает дилер.
